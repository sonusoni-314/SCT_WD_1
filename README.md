# SCT_WD_1

Responsive ecommerce landing page built for SkillCraft Technology Task 01. The page features a fixed interactive navigation bar, hover-driven product cards, and a fully responsive layout.

## Features
- Fixed navigation with scroll state styling
- Product cards with hover color shift and image zoom
- Responsive layout for desktop, tablet, and mobile
- Deals banner and newsletter section

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Getting Started
Open the project locally:
1. Open `index.html` in your browser
2. Or run a local server:
   - `python -m http.server 5500`
   - Visit `http://localhost:5500`

## Project Structure
- `index.html` - Main page markup
- `style.css` - Styles and responsive layout
- `script.js` - Scroll and menu behavior
